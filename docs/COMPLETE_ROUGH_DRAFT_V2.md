# Complete Rough Draft v2.0

## Design target

A complete beginning-to-ending gameplay draft with the major visual-production pass intentionally deferred.

## Roster

15/15 classes are playable. The final five added here are Bard, Druid, Sorcerer, Warlock, and Wizard. Mage remains the immediate elemental-control caster; Wizard is deliberate arcane precision; Sorcerer is volatile burst; Warlock trades safety for drain/pact power; Bard builds tempo and self-buffs; Druid controls space and sustains.

## Combat

- 360-degree aim vector from mouse or controller right stick.
- Directional projectile launch.
- Directional melee hit volumes.
- Ground, aerial, crouched, and movement-state attacks use the same aim architecture.
- Mouse light/heavy attacks coexist with J/K.
- All fifteen champions retain class-specific abilities and ultimates.

## Movement

- run/acceleration/deceleration
- coyote time
- jump buffering
- variable jump height
- wall slide / wall jump
- class-specific dash
- Rogue air jump
- crouch with a physically smaller collision capsule
- low crawl-space traversal
- crouch + dash slide
- independent aim while moving

## World architecture

Five optional branch networks were added without breaking the main campaign:

1. Bellkeeper Undercrypt — crawl tunnel, lever shortcut, alternate village route.
2. Rootway — underground Whispering Woods loop and optional encounters.
3. Drowned Aqueduct — Sunken Keep sub-dungeon with paired portal traversal.
4. Ashen Caves — alternate mountain route beneath exposed wind sections.
5. Rift Gallery — Black Tower folded-space route using multiple portals.

Each branch rejoins the campaign. No class is required to use a class-specific ability to finish the game.

## Existing complete campaign systems retained

Story/cutscenes, safe NPC dialogue, five Arcane Shards, eight checkpoint shrines and blessings, save/continue, death/retry, Movement Lab, region music, combat SFX, minibosses, region bosses, Memory Labyrinth, Storm Vane puzzle, Arcane Mirror puzzle, Crown Sigils, four-phase True Evil Wizard, conditional all-shards ending, and victory flow.

## Test focus

This is the full-playthrough mechanics draft. Runtime playtesting should now focus on route clarity, difficulty spikes, portal/tunnel placement, crouch headroom, mouse/right-stick feel, directional hit detection, all fifteen class kits, boss compatibility, save/continue, and progression sequencing.
