# Patch v2.0.2 — Arcane Mirror Alignment Feedback

The Arcane Mirror puzzle now uses the same confirmation language as the Storm Vane puzzle.

- Correctly aligned mirrors display a persistent check mark.
- Correct alignment produces stronger audio and an `ALIGNED` message.
- The existing `ARCANE MIRRORS x / 3` tracker remains visible.
- Rotating a mirror away from its correct direction removes its check mark and updates the tracker.

The Mirror Vault is an alignment puzzle, not a hidden combination lock. Its story clue identifies the intended directions:
- Moon → UP
- Heart → RIGHT
- Road → LEFT
