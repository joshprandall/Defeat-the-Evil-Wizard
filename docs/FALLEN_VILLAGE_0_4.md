# Fallen Village 0.4

## Purpose

The Fallen Village build establishes the first repeatable campaign template: exploration, optional rewards, environmental storytelling, checkpoint progression, a miniboss gate, a post-boss recovery space, and a major boss transition.

## Player experience target

The region should feel like a journey rather than a single combat corridor. The player should alternate between movement, combat, elevated platform choices, short recovery windows, optional shard collection, and two arena-scale encounters.

## New systems

### Arcane Shards
Five one-run collectibles provide immediate recovery and class-resource value. The full set provides a stronger restoration reward. The system is intentionally simple so it can later grow into permanent relics, secrets, challenges, and class-specific upgrades.

### Miniboss encounter framework
The Grave Knight establishes a reusable miniboss contract:
- separate arena lock;
- dedicated health display;
- telegraphed attacks;
- phase transition;
- retry reset;
- checkpoint advancement after victory.

### Environmental landmarks
Procedural village props and backdrop silhouettes create recognizable progression beats without committing the project to final production art before mechanics stabilize.
