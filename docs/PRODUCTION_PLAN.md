# Production Plan

The project is now being developed as a complete game rather than a vertical-slice experiment.

## Completion gates

1. **Production core** — at least two mechanically distinct champions, stable movement, combat, boss flow, controller support, HUD, death/retry, and automated tests.
2. **World structure** — authored regions, transitions, checkpoints, secrets, enemy families, minibosses, and progression.
3. **Champion roster** — all fifteen original classes implemented with distinct traversal/combat identities.
4. **Content complete** — full route to the Black Tower, final encounter, endings, difficulty settings, save data, accessibility settings, and credits.
5. **Art/audio polish** — production sprites or equivalent authored art, animation, effects, environment art, music, sound mix, menus, and visual consistency.
6. **Release candidate** — performance pass, controller/keyboard testing, regression testing, packaging, and final balance.

## Immediate next production milestone
Build the first authored region around the movement system rather than adding disconnected features. The Fallen Village should teach movement and combat through level geometry, introduce the first NPC/story beat, contain a secret route, and culminate in a miniboss.
